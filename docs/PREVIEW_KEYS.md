# Ключи CSS-превью (контракт панель ↔ пресеты)

Каждый пресет получает один ключ `preview` (карта в `src/28_previews.jsx`, `UK.PREVIEW[id] = key`).
Панель рисует для ключа маленькую CSS-анимацию (контейнер 16:9, внутри «кадр» и «объект»), которая
играет при наведении на карточку. Ключи:

| ключ | что анимировать |
|---|---|
| fadeIn / fadeOut | объект проявляется / исчезает по прозрачности |
| slideIn / slideOut | объект въезжает слева / уезжает вправо (панель поворачивает по data-dir не нужно) |
| scaleIn / scaleOut | масштаб 0→1 / 1→0 |
| popIn / popOut | масштаб с перелётом (overshoot) |
| spin | вращение вокруг оси Z с появлением |
| flip | 3D-поворот вокруг Y |
| blurIn / blurOut | blur 12px→0 + прозрачность |
| wipe | объект открывается шторкой слева направо (clip-path) |
| blinds | жалюзи (полосы, repeating-linear-gradient mask) |
| iris | круглая маска растёт |
| bounce | падение сверху с отскоком |
| elastic | пружинящий масштаб |
| glitch | рывки, RGB-смещение, полосы |
| pixel | мозаика → чёткий (image-rendering + scale трюк или блоки) |
| flash | белая вспышка |
| shake | дрожание кадра |
| zoom | резкий зум кадра |
| whip | быстрый горизонтальный смаз-пролёт |
| push | один кадр выталкивает другой |
| dissolve | кроссфейд двух кадров |
| rgb | RGB split / хроматика |
| twist | закручивание |
| ripple | концентрические круги |
| wave | волнообразное искажение |
| bulge | раздувание |
| mirror | зеркало по центру |
| kaleido | калейдоскоп (сегменты) |
| sweep | блик пробегает по объекту (light sweep) |
| rays | лучи света от центра |
| leak | тёплый light leak (оранжевое пятно плывёт) |
| glow | свечение пульсирует |
| grade | цветокор: кадр меняет оттенок |
| grain | зерно (шум) |
| vignette | виньетка |
| letterbox | чёрные полосы сверху/снизу |
| typewriter | текст печатается по буквам |
| textUp | буквы выезжают снизу |
| textScale | буквы появляются масштабом |
| counter | числа меняются |
| camera | плавный зум/панорама кадра (Ken Burns) |
| orbit | 3D-орбита (perspective rotateY качание) |
| stretch | растяжение по оси |
| roll | прокрутка кадра вверх (пролёт) |
| swing | маятник сверху |
| squash | squash & stretch |
| pan | панорама вбок |
| echo | шлейф копий |
| strobe | мигание |
| shadow | тень выезжает |
| liquid | жидкое искажение (blob) |
| tool | иконка-утилита (шестерёнка/клипса), лёгкая пульсация |
| combo | несколько элементов по очереди: появление + блик + уход |
| bar | плашка титра раскрывается по ширине + акцентная полоска (design) |
| line | линия рисуется из точки (trim), затем стирается (design) |
| frame | рамка/уголки вокруг кадра проявляются с лёгким масштабом (design) |
| grid | сетка точек/линий фоном проявляется и дрейфует (design) |
| burst | кольца/лучи расходятся из центра и растворяются (design) |
| progress | полоса прогресса заполняется до ~75 % (design) |
| spinner | дуга-спиннер вращается (design) |
| badge | круглый бейдж выскакивает, кольцо расходится (design) |
