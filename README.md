# UniKit — универсальный тулкит для монтажа в After Effects 2025

Панель для AE 2025 (CEP-интерфейс с вкладками, hover-превью и иконками + резервная ScriptUI-версия). 560 пресетов в 11 категориях, включая «Дизайн» (shape-графика: плашки, рамки, бейджи, фоны, callouts) и 67 готовых решений. с библиотекой готовых пресетов в духе
Animation Composer / Motion Bro / EditKit / AtomX: анимации появления и исчезновения, переходы,
эффекты и луки, искажения, свет и лайтсвипы, текстовые анимации, движение камеры и утилиты.
Один клик — пресет применяется на выделенные слои. Всё строится на штатных эффектах AE
(включая Cycore CC), никаких внешних плагинов.

## Установка

### Быстро

Запустите `install.bat`. Он установит CEP-панель в `%APPDATA%\Adobe\CEP\extensions\com.unikit.panel`,
включит режим неподписанных расширений (PlayerDebugMode в HKCU\Software\Adobe\CSXS.9–12) и положит
резервную ScriptUI-панель в папки ScriptUI Panels. После перезапуска AE: **Window > Extensions > UniKit**.

### Обновление

* Кнопка **⟳ Обновить** в шапке панели — запускает `update.bat` в отдельном окне консоли (путь к папке проекта
  установщик сохраняет в `repo_path.txt` рядом с панелью). После завершения перезапустите AE.
* Или вручную: `update.bat` в папке проекта. Он делает `git fetch` + `git pull --ff-only` из GitHub
  (локальные правки откладывает в `git stash`), пересобирает `dist/UniKit.jsx` (если есть node) и тихо
  переустанавливает обе панели (`install.bat /silent`). Показывает список изменений между версиями.

### Вручную (ScriptUI-версия)

1. Соберите (или возьмите готовый) `dist/UniKit.jsx`:
   ```
   node build.js
   ```
2. Запустите `install.bat` — он скопирует панель в папки ScriptUI Panels всех найденных версий AE
   (пользовательскую `%APPDATA%\Adobe\After Effects\<версия>\Scripts\ScriptUI Panels` без прав админа и
   системную `...\Support Files\Scripts\ScriptUI Panels`, если есть права).
   Либо скопируйте файл вручную в
   `C:\Program Files\Adobe\Adobe After Effects 2025\Support Files\Scripts\ScriptUI Panels\`.
3. Перезапустите AE → **Window > UniKit.jsx**. Панель можно закрепить в рабочем пространстве.
4. Если выражения не создаются: Edit > Preferences > Scripting & Expressions →
   включить «Allow Scripts to Write Files and Access Network».

## Панель (CEP)

* Вверху — вкладки категорий с иконками (появление, исчезновение, переходы, эффекты, искажения, свет, текст, камера, утилиты, готовые решения, избранное).
* Карточки пресетов с анимированным превью при наведении; клик — выбрать, двойной клик или Enter — применить, звезда — в избранное.
* **Превью** — применяет пресет на выделенный слой в отдельной undo-группе, ставит рабочую область на анимацию и запускает предпросмотр; затем **Оставить** или **Отменить**.
* Настройки с иконками и подсказками; статус-бар показывает текущее выделение и предупреждает, если пресету нужен текстовый слой или два слоя для перехода.
* **Готовые решения** — связки появление + лук/свет + уход (или переход + эффекты на склейке): Logo Reveal, Cinematic Clip, Glitch Intro, Lower Third, Vlog Cut, Impact Hit, текстовые заголовки и т.д.

Разработка панели без AE: `node cep/com.unikit.panel/dev/serve.js` → http://localhost:5178 (каталог из `dev/catalog.json`, пересоздать: `node cep/com.unikit.panel/dev/gen_catalog.js`).

## Использование (ScriptUI-версия)

* Выделите слой(и) → выберите категорию в выпадающем списке → двойной клик по пресету (или «Применить»).
* Поиск ищет по всем категориям сразу (англ. и рус. теги).
* `★` — избранное, своя категория «★ Избранное».

### Настройки

| Параметр | Что делает |
|---|---|
| **Длит., с** | длительность анимации / перехода |
| **Изинг** | Smooth, Expo Out/In/In-Out, Soft, Back (перелёт), Bounce (отскок), Elastic (пружина), Linear. Back/Bounce/Elastic добавляют выражение поверх ключей, амплитуда — слайдерами «UK: Amp / Freq / Decay» |
| **Направление** | ← → ↑ ↓ для slide/wipe/whip и всего, где есть геометрия |
| **Сила %** | амплитуда / интенсивность (расстояние, размытие, искажение…) |
| **Старт** | от границы слоя (in-point для появлений, out-point для исчезновений) или от курсора |
| **Шаг, с** | задержка между слоями при применении на несколько слоёв (каскад) |
| **Слайдеры-контролы** | параметры пресета выносятся в Effect Controls как `UK: …` и управляют эффектами через выражения — можно крутить после применения |
| **На корр. слой** | эффекты/искажения/свет/камера применяются на новый корректирующий слой над выделением (или над всей композицией, если ничего не выделено) |

### Переходы

* Выделите **два соседних слоя** — склейка = начало верхнего (позднего) слоя.
* Или **один слой** и поставьте курсор на склейку.
* Эффектные переходы (zoom, spin, glitch, whip…) создаются на корректирующем слое `UK · …` длительностью
  «Длит.» вокруг склейки; «честные» (push, slide, wipe, flip…) анимируют сами слои.

### Текст

Пресеты категории «Текст» работают с текстовыми слоями через аниматоры (Range Selector) — их можно
дорабатывать вручную в свойствах слоя.

### Удаление

Кнопка **«Удалить UK»** снимает все эффекты и контролы UniKit с выделенных слоёв (ключи на transform остаются —
их удобно снимать стандартно). Всё, что добавляет панель, имеет префикс `UK · ` / `UK: `.

## Свои пресеты

Добавьте файл в `src/presets/` с `UK.add({...})` (см. `docs/API.md`), соберите `node build.js`,
прогоните `node test/run.js`. Пресет получает контекст `c` с готовыми временами, изингом,
направлением и силой, а хелперы `UK.key2 / UK.keys / UK.addFx / UK.set / UK.cv` берут на себя
ключи, безье-ручки, эффекты и слайдеры.

## Тестирование

* `node test/run.js` — быстрый прогон в node через мок AE (ловит ошибки кода, типов значений, баланс
  выражений, неизвестные match names эффектов).
* `test/ae_selftest.jsx` в самом AE — применяет каждый пресет в трёх режимах на тестовой композиции и
  пишет отчёт `UniKit_selftest.txt` на рабочий стол. Запускать на пустом проекте.

## Требования

After Effects 2025 (25.x); работает и на 2022–2024. Выражения — движок JavaScript (по умолчанию с AE 16).
